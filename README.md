# FIFA World Cup Data Analysis — Project Branch

This branch contains the completed version of my first Data Analyst portfolio project based on FIFA World Cup historical data from 1930 to 2026.

## Project Overview

The objective of this project was to transform and analyse historical FIFA World Cup data using Microsoft Excel, from raw data preparation to interactive dashboards.

The project covers:

- Data cleaning and standardisation
- Data quality control
- Historical match analysis
- KPI creation
- Descriptive statistics
- Team performance analysis
- Offensive and defensive performance scores
- Team comparison
- Probability modelling
- Interactive dashboards

## Workbook Structure

The Excel workbook is organised into several layers:

- `RAW_DATA` — original source data
- `DATA_QUALITE` — data quality checks and validation
- `DATA_CLEANED` — cleaned and standardised data
- `CALCULES` — intermediate calculations
- `RESUME` — aggregated statistics and KPIs
- `DASHBOARD` — visual analysis and key insights
- `VERSUS` — comparison between two teams

## Key Features

The analysis includes:

- Matches and results by tournament
- Goals scored and conceded
- Wins, draws and losses
- Median goals per match
- Goal difference
- Clean sheets
- Highest stage reached
- Team participation
- Offensive and defensive performance scores
- Overall performance score
- Team-versus-team comparison
- Estimated match outcome probabilities

## Methodology

The project uses Excel formulas and statistical methods to transform the raw data into analytical indicators.

The offensive and defensive scores are custom analytical metrics developed for this project. They are not official FIFA rankings.

The probability model is also an analytical model based on the available historical data and should not be interpreted as an official prediction.

## Data Quality

A dedicated data-quality layer was created to identify and correct issues such as:

- Inconsistent team names
- Historical team names
- Encoding and special-character issues
- Missing or malformed values
- Inconsistent tournament stage names
- Duplicate or anomalous records
