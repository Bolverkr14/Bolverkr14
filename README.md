# Portfolio Data Analyst | Yann Lecompte

Bienvenue sur mon portfolio de projets en analyse de données et Business Intelligence.

## À propos de ce GitHub

J’ai créé ce GitHub afin de documenter ma progression et de présenter les projets réalisés dans le cadre de ma transition professionnelle vers le métier de Data Analyst.

Ce portfolio me permet de mettre en pratique les différentes étapes d’un projet de données :

- compréhension du besoin métier ;
- collecte et exploration des données ;
- contrôle de la qualité des données ;
- nettoyage et transformation ;
- analyse statistique ;
- création d’indicateurs de performance ;
- conception de tableaux de bord ;
- présentation des résultats et recommandations.

L’objectif est de montrer ma capacité à transformer des données brutes en informations claires, structurées et utiles à la prise de décision.

## Objectif professionnel

Je souhaite évoluer vers un poste de Data Analyst junior dans lequel je pourrai contribuer à :

- fiabiliser et structurer les données ;
- automatiser des analyses récurrentes ;
- construire des indicateurs pertinents ;
- concevoir des tableaux de bord ;
- identifier des tendances et des anomalies ;
- communiquer les résultats de manière claire aux équipes métier.

## Compétences développées

### Analyse et préparation des données

- exploration de données ;
- nettoyage et normalisation ;
- gestion des valeurs manquantes ;
- détection des doublons et des anomalies ;
- création de règles de contrôle qualité ;
- analyse descriptive ;
- création de KPI.

- SQL ;

### Compétences transversales

- compréhension des besoins métier ;
- rigueur et contrôle de la qualité ;
- documentation des traitements ;
- résolution de problèmes ;
- data visualisation ;
- communication des résultats.

## Projets

Chaque projet présente autant que possible :

1. le contexte et l’objectif métier ;
2. les données utilisées ;
3. les contrôles qualité réalisés ;
4. les méthodes de nettoyage et de transformation ;
5. les indicateurs construits ;
6. les visualisations et tableaux de bord ;
7. les principaux résultats ;
8. les limites et pistes d’amélioration.
